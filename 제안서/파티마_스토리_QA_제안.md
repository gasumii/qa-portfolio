# 트릭컬 파티마 — 스토리 콘텐츠 QA 테스트 제안

> 작성자: 이영준
> 작성 관점: 트릭컬 리바이브 2.5년+ 코어 유저 + 라이브 게임 모니터링·패치 검증 실무자

---

## 제안 배경

트릭컬 리바이브의 가장 큰 강점이자 정체성은 **풀더빙 기반의 메인·이벤트 스토리**입니다.
파티마는 게임 시스템에 변화가 있을 수 있으나, 원작에서 검증된 핵심 매력인 **풀더빙 스토리 경험**은
후속작에서도 계승될 가능성이 높다고 판단했습니다. 또한 서브컬처 게임의 스토리는 캐릭터 수집 BM에서
캐릭터의 매력을 어필하고, 이는 게임 수익에 큰 영향을 주기에 스토리 검증을 제안으로 선택하였습니다.

스토리 콘텐츠는 **더빙(음성) · 자막(텍스트) · 연출 · 분기**가 복합적으로 얽혀 있어,
QA 관점에서 검증 포인트가 많고 유저 체감 품질에 직결되는 영역입니다.
원작에서 스토리 영역 테스트 케이스 500건 이상을 작성한 경험을 바탕으로, 파티마 스토리 QA 방향을 제안합니다.

---

## 1. 더빙(음성) 검증

| 테스트 포인트 | 확인 내용 | 우선순위 |
|---|---|---|
| 음성-자막 싱크 | 음성 재생과 자막 출력 타이밍 일치 | High |
| 음성 누락 | 대사에 배정된 음성이 정상 재생되는가 (무음 없음) | High |
| 음성 중복/겹침 | 이전 대사 음성이 다음 대사와 겹쳐 재생되지 않는가 | Medium |
| 스킵 시 음성 처리 | 스토리 스킵 시 재생 중 음성이 즉시 정지되는가 | Medium |
| 자동 진행 시 음성 | 자동 진행 모드에서 음성 끝까지 재생 후 다음 대사로 | Medium |
| 배속 시 음성 | 배속 기능 사용 시 음성 처리가 의도대로인가 | Medium |

## 2. 자막·텍스트 검증

| 테스트 포인트 | 확인 내용 | 우선순위 |
|---|---|---|
| 자막-음성 내용 일치 | 자막 텍스트와 실제 음성 대사 내용이 일치하는가 | High |
| 텍스트 오버플로우 | 긴 대사가 대사창을 벗어나거나 잘리지 않는가 | Medium |
| 화자 이름 표기 | 대사별 화자 이름이 정확히 표기되는가 | Medium |
| 특수문자·기호 | 특수문자·문장부호·이모지가 깨지지 않는가 | Low |
| 다국어 대응 | 번역문 길이로 인한 레이아웃 깨짐 여부 | Medium |

## 3. 연출·분기 검증

| 테스트 포인트 | 확인 내용 | 우선순위 |
|---|---|---|
| 선택지 분기 | 선택지 선택 시 의도한 분기로 정상 진행되는가 | High |
| 컷신·연출 재생 | 스토리 중 컷신·이펙트·배경 전환이 정상 재생되는가 | High |
| 이어보기 | 스토리 중 이탈 후 복귀 시 진행 지점부터 이어지는가 | High |
| 진행도 저장 | 스토리 진행 상태가 정상 저장/불러오기 되는가 | High |
| 반복 시청 | 완료한 스토리를 다시보기에서 정상 재생하는가 | Medium |
| 스토리 보상 지급 | 스토리 완료 시 보상이 정상 지급되는가 | High |

## 4. 환경·성능 검증

| 테스트 포인트 | 확인 내용 | 우선순위 |
|---|---|---|
| 저사양 기기 | 저사양 단말에서 컷신 프레임 드랍·로딩 지연 여부 | Medium |
| 네트워크 불안정 | 스토리 진행 중 통신 끊김 시 데이터 정합성 | High |
| 해상도 대응 | 다양한 화면 비율·해상도에서 자막·UI 배치 정상 여부 | Medium |
| OS별 동작 | Android/iOS에서 음성·자막 동일하게 동작하는가 | Medium |

---

## 우선순위 산정 기준

라이브 서비스 운영 관점에서, 아래 기준으로 우선순위를 산정했습니다.

- **High**: 스토리 진행 자체를 막거나(이어보기·분기·저장), 트릭컬에서 강점이던 풀더빙 계승을 위한 음성 검증(음성-자막 싱크·보상 지급)에 해당하는 항목
- **Medium**: 체감 품질을 저하하나 진행은 가능한 항목
- **Low**: 경미한 표기·UX 이슈

## 제안자 강점

- 트릭컬 리바이브 스토리 영역 테스트 케이스 500건 이상 직접 작성 경험
- 라이브 게임 모니터링·패치 검증 실무 (이상 감지 → 심각도 판단 → 전파 → 기록)
- 코어 유저로서 트릭컬 스토리 연출·더빙의 특성 이해
