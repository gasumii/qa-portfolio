# 버그 리포트 — 트릭컬 리바이브

실제 플레이 및 공식 오류 게시판을 기반으로 작성한 버그 리포트입니다.
심각도 · 우선순위 · 재현율 · 재현 환경 · 재현 절차를 포함해 실무 양식으로 정리했습니다.

> **총 16건** — 라이브 이슈 1건 · 오류 게시판 3건 · 교단 콘텐츠 9건 · 이벤트 배포 전 검증 3건
> **ID 체계** `BUG-LIVE-` 라이브 장애 / `BUG-BRD-` 공식 오류 게시판 / `BUG-CLT-` 교단 콘텐츠 / `BUG-EVT-` 이벤트 배포 전 검증
> **상태 값** `Open` 미착수 · `In Progress` 처리 중 · `Resolved` 처리 완료
