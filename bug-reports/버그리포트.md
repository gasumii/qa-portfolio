# 버그 리포트 — 트릭컬 리바이브

실제 라이브 이슈와 공식 라운지 오류 게시판의 유저 제보를 실무 양식으로 정리하고, 배포 전 검증 흐름을 보여 주는 가상 시나리오 3건을 더한 버그 리포트입니다.
리포트마다 심각도 · 우선순위 · 재현 환경 · 재현율 · 재현 절차 · 예상 동작 · 실제 동작 · 상태를 적었습니다.

> **총 16건** — 실제 이슈 13건(라이브 이슈 1 · 오류 게시판 3 · 교단 콘텐츠 9) + 가상 시나리오 3건(이벤트 배포 전 검증)
> **검증 중 1건** (BUG-COM-001) — 직접 재현 확인 전이라 총계에 넣지 않음. 재현되면 총계에 반영
> **ID 체계** `BUG-LIVE-` 라이브 이슈 / `BUG-BRD-` 공식 오류 게시판 / `BUG-CLT-` 교단 콘텐츠 / `BUG-EVT-` 이벤트 배포 전 검증 / `BUG-COM-` 커뮤니티 제보 검증
> **심각도** `Critical` 진행 불가·데이터 손실·크래시 · `Major` 핵심 기능 오작동, 우회 방법 없음 · `Minor` 기능 일부 오작동, 우회 가능 · `Trivial` 오탈자·미세한 UI 문제
> **상태 값** `Open` 확인됨·미처리 · `진행중` 개발팀 전달·수정 중 · `Resolved` 수정 완료·재테스트 필요 · `Closed` 재테스트 통과·종결 · `보류` 우선순위 낮음 또는 스펙 확정

| 구분 | 건수 | 근거 | 직접 재현 |
|---|---:|---|---|
| 1. 라이브 이슈 | 1건 | 공식 공지 + 본인 환경 관찰 | 에뮬레이터에서 재현, iOS 실기기에서 정상 확인 |
| 2. 오류 게시판 | 3건 | 공식 라운지 오류 게시판 유저 제보 | 없음 (제보 기준) |
| 3. 교단 콘텐츠 | 9건 | 공식 라운지 오류 게시판 유저 제보 | 없음 (제보 기준) |

| 5. 커뮤니티 제보 검증 중 | 1건 (총계 제외) | 커뮤니티 제보 영상의 프레임 분석 | 재현 확인 대기 |
