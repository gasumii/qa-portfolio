## 보고서 1 — 트릭컬 리바이브 전투 판정 실측 검증 보고서

📄 **[PDF 보기](이영준_QA포트폴리오1_전투판정실측검증.pdf)** · 작성 2026.11.01 · 국내 서버 · 실측 기간 2026.10.26 ~ 11.01

### 요약
1. **벨라가 영속을 가진 채 쓰러지면 영속이 먼저, 영속이 없으면 비비(신성) 어사이드3이 먼저 발동했습니다.** 영속의 "모든 HP 회복"은 최대 HP 25%씩 4회, 약 1초 안에 끝나는 회복이었습니다.
2. **무적은 피격 트리거보다 먼저 처리됩니다.** 셀리네 고학년 무적 중에는 맞아도 "피격 시 SP 10"이 오르지 않았습니다.
3. **12건 중 설명대로 동작이 예상되는 것은 2건뿐이었습니다.** 8건은 설명에 답이 없었고 2건은 설명과 실제가 달랐습니다. 이 중 5건을 표기 개선 제안으로 묶었습니다.

### 검증 방법
- 국내 전 사도 136명의 스킬을 효과 단위 1,883줄로 나눈 전투 판정 DB에서, 설명이 비어 있거나 겹칠 때의 순서가 불분명한 줄만 골라 실측
- 조건을 고정할 연습장이 없어 모든 실측은 보스전을 미리 체험할 수 있는 '딜리버리'에서 진행. 항목마다 3~10판 반복, 절대값이 아닌 비율·순서·횟수로만 결론
- 의도된 동작인지 알 수 없으므로 오류로 단정하지 않고 **정상 동작 확인 / 표기 개선 제안 / 판정 미확정**으로만 분류

### 결과

| No | 대상 | 결과 | 분류 |
|---|---|---|---|
| EXP-01 | 벨라 영속 × 비비(신성) 어사이드3 | 영속 보유 시 영속이 먼저, 미보유 시 비비 어사이드3이 먼저 | 정상 동작 |
| EXP-02 | 셀리네 무적 중 피격 SP | 무적 중 피격은 SP 회복 트리거를 발동시키지 않음 | 정상 동작 |
| EXP-03 | 다야 쓰라림 재부여 | 덮어쓰지 않고 따로 쌓이며, 지속 시간도 각자 흐름 | 표기 개선 |
| EXP-04 | 깜짝 상자 (스펠) | 기절 면역 보스에게도 "기절 건 적" 대상 피해가 들어감 | 표기 개선 |
| EXP-05 | 키디언 저학년 공격 횟수 | 아티팩트 1개당 +1회 (0~3개 → 1~4회), 어사이드2 시 +1 | 정상 동작 |
| EXP-06 | 도깨비 감투 발동 기준 | HP 정확히 20.0%에서 무적 발동 (표기와 일치) | 정상 동작 |
| EXP-07 | 레비의 단도·풍선 갑옷 재발동 | 전투당 1회. 회복해 기준선을 다시 넘어도 재발동 없음 | 표기 개선 |
| EXP-08 | 기준선을 넘는 큰 피해 | 기준선까지만 깎이고 넘친 피해는 버려짐 | 정상 동작 |
| EXP-09 | 레비의 단도 부가 버프 | 피해량·공격 속도 증가가 함께 붙고 함께 사라짐 (7초) | 정상 동작 |
| EXP-10 | 페스타 고학년 조명 | 조명 세 가지 효과가 한 번에 모두 적용 (10판 중 10판) | 표기 개선 |
| EXP-11 | 벨라 존속 최대 HP 30% | 다른 HP% 보너스와 더해서 계산 (합연산) | 표기 개선 |
| EXP-12 | 벨라 영속 회복 방식 | 존속 적용 후 최대 HP의 25% × 4회, 약 1초 안에 완료 | 정상 동작 |

**표기 개선 제안 우선순위** — 라이브에서 유저가 "버그"로 느끼고 문의할 가능성 기준
1. 레비의 단도 · 풍선 갑옷 (전투 중 바로 보이는 차이) → 2. 깜짝 상자 → 3. 페스타 고학년 → 4. 다야 쓰라림 → 5. 벨라 존속

**회귀 항목** — 결과를 패치 때 다시 확인할 항목 R-1 ~ R-10으로 정리 (전투불능 방지 효과 소모 순서, 무적 중 피격 트리거, 같은 상태의 중첩 규칙, CC 면역 대상 조건 효과, HP 기준선 발동 값·횟수, % 보너스 연산 방식 등)

## 보고서 2 — 트릭컬 리바이브 글로벌·국내 서버 간 스킬 차이 검증 리포트

📄 **[PDF 보기](이영준_QA포트폴리오2_서버간스킬차이검증.pdf)** · 작성 2026.10.30 · 데이터 기준 2026.10.29 (국내 1.6.66 / 글로벌 1.6.1-asia-res8.16061)

### 요약
1. **스킬 112줄 중 같은 줄은 6줄.** 14명 중 12명은 역할 자체가 바뀐 재설계 수준이었습니다.
2. **한국 1덱이던 네르가 글로벌 97덱.** 두 서버에 모두 있는 사도인데 채용이 갈린 원인을 스킬 차이에서 찾았습니다.
3. **보유 5명은 게임 화면, 미보유 6명은 Lv1 화면으로 대조하고 14줄은 '검증 필요'로 공개.** 차이 7개 항목은 회귀 체크리스트로 정리했습니다.

### 검증 방법
- 2026.10 프론티어를 국내 1~300위 300덱, 글로벌 1~100위 100덱으로 순위 화면에서 직접 기록
- 글로벌 미출시 사도 6명은 빼고, 두 서버에 모두 있는 사도끼리만 비교
- 글로벌 채용 상위 14명의 스킬을 8칸(저학년·고학년·일반 공격·강화 공격·패시브·어사이드2·3·사도 전체 능력치), 스킬 Lv10 기준으로 국내 DB와 한 줄씩 대조
- 출처 우선순위는 게임 화면 → 위키. 위키는 참고 자료로 해외 위키 [Loot & Waifus](https://lootandwaifus.com/)의 사도별 페이지(2026.10.29 열람, 스킬 Lv.10)를 사용. 위키를 그대로 쓰지 않은 사례(표기 오류·Lv1 값 오기입)는 근거 화면과 함께 기록

### 차이 구성 (112줄)

| 효과 변경 | 글로벌 전용 | 수치 상향 | 수치 하향 | 같음 | 확인 필요 |
|---:|---:|---:|---:|---:|---:|
| 48 | 14 | 18 | 12 | 6 | 14 |

### 라이브 이슈 대응으로 연결
- 국내 리워크가 글로벌에 아직 반영되지 않은 것으로 보이는 값(이드 강화 공격)을 **인지 → 분류 → 우선순위 → 전달** 순서로 정리하고, 원인을 단정하지 않는 확인 요청 예시를 작성
- 서버마다 따로 봐야 하는 항목 7개를 회귀 체크리스트로 정리 (패시브 유무, 고학년 재사용 시간, 사도 전체 능력치, 어사이드3 받는 피해 감소, 전투불능 무효화 계열 발동 순서, 강화 공격 발동 조건, 국내 리워크 반영 여부)
