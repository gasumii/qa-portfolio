# Section E — 트릭컬 리바이브 전투/밸런스 TC (25건) + 라이브 이슈 대응 체크리스트 (13항목)

> 에피드게임즈 [트릭컬 리바이브] QA담당자 공고(전투/밸런스 QA, 국내/글로벌 라이브 이슈 대응)에 맞춰 2026.10 새로 설계한 자료입니다.
> **실제 빌드에서 실행한 기록이 아닌 테스트 설계 샘플**이며, 포트폴리오 TC 합계(1,189건)와 별도로 집계합니다.
> 성격 시너지가 성격별로 독립 적용되고 해당 성격 사도에게만 걸린다는 규칙은 인게임에서 확인했습니다(2026.10.02). 단계별 수치(+20/55/100/140/200%)는 공개 커뮤니티 자료 기준 참고값입니다.
