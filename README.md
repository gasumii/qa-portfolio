## 파티마 QA 제안 (후속작)

원작 트릭컬 리바이브의 핵심 강점인 **풀더빙 스토리**를 후속작 파티마 QA에 적용한 테스트 설계 제안입니다.
서브컬처 게임에서 스토리가 캐릭터 수집 BM·수익에 직결된다는 관점에서, 더빙 · 자막 · 연출 · 환경 4개 영역의 검증 방향을 정리했습니다.

- [파티마 스토리 QA 제안서](./제안서/파티마_스토리_QA_제안.md)

## 작성 관점

- **두 가지 양식 병행**: 실무 대량 테스트 양식(Section A) + ISTQB 표준 양식(Section B)
  → 대량 실전 처리 능력과 표준 방법론 이해를 모두 갖춤
- **코어 유저 시각**: 게임 시스템 · 메타 · 확률 구조를 깊이 이해한 상태에서 검증
- **라이브 운영 실무 반영**: 이상 감지 → 심각도 판단 → 부서 전파 → 기록 사이클 경험
