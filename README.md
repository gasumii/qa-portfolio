# 트릭컬 리바이브 QA 포트폴리오

서브컬처 수집형 RPG **트릭컬 리바이브**를 2.5년 이상 플레이한 코어 유저 관점에서 작성한 QA 산출물 모음입니다.
실제 플레이와 공식 오류 게시판을 기반으로, 테스트 케이스·버그 리포트·배포 전 체크리스트를 직접 작성했습니다.

## 구성

| 문서 | 내용 |
|------|------|
| [테스트 케이스](./01_test-cases.md) | 테마극장 로비 HUD 기능 테스트 케이스 39건 (통과율 집계 포함) |
| [버그 리포트](./02_bug-reports.md) | 실제 발견 버그 리포트 (재현 환경·재현율·심각도·우선순위 포함) |
| [배포 전 체크리스트](./03_checklist.md) | 패치 배포 전 점검 항목 체크리스트 |

## 작성 관점

- **코어 유저 + 라이브 운영 실무자**의 이중 시각으로 작성
- 넥슨 협력사에서 라이브 게임 모니터링·패치 검증 실무 경험 반영
- 심각도(Severity)·우선순위(Priority)를 서비스 영향도 기준으로 분류

## 사용 도구

- 문서: Markdown / Excel
- 버전 관리: Git / GitHub
- 이슈 트래킹: Jira / Confluence (실무 경험)
- 자격증: ISTQB CTFL (취득 준비 중, 2026)

## 작성자

라이브 게임 모니터링·패치 검증 실무 / 게임 QA 직무 지향
